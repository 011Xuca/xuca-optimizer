# Changes

English changelog of **Brío** (the app shows the section of your version when the language is English).

## v1.0.13

### New
- **Gamer zone, Keyboard: Focus mode without a program (anti-cheat friendly)** (new, not in any profile): turns off both Windows keys from the registry (`Scancode Map` in `HKLM\SYSTEM\CurrentControlSet\Control\Keyboard Layout`), with no program or keyboard hook, so Vanguard, FACEIT and other anti-cheats see nothing. It keeps the map you already have (for example Caps Lock → Ctrl): it only adds the two missing entries, writes how it was in `ProgramData\Brio\scancode_orig.txt`, and Reset removes only what Brío added (if nothing is left, it deletes the value). The Windows keys stay off always and for every user, and it asks to restart. It conflicts with **Focus mode** (the app asks which one to keep), and the Focus mode warning now suggests this option for games with anti-cheat.
- **System apps: Microsoft Edge WebView2 Runtime** (protected, unchecked): it is removed with its own uninstaller (`setup.exe --uninstall --msedgewebview --system-level --force-uninstall`, with a 3-minute limit), Brío checks it is gone and sets the Edge Update policy that keeps it from reinstalling by itself. The protected apps dialog warns strongly: the new Teams, Office, Widgets, Microsoft account sign-in in some apps and many desktop programs use it and may fail or not open. Removing only Edge still keeps it.
- **System services gathers the loose services**: the NVIDIA container, the compatibility inventory and Windows Health, local network and casting (8 services), Remote Desktop (3), Themes and Windows AI (AI Fabric) are no longer separate options and join the list as **Extreme** (never checked by default). They turn off and restore the same as before; **Minimal RAM** still turns off the local network and Remote Desktop, and "Scan and repair" turns the inventory back on before updating. Each service and each app in **System apps** says in one line what it is and what you gain (+) and lose (-) by turning it off or removing it.
- **Copilot is respected**: if you say you use Copilot and AI when applying a profile, System apps no longer removes Copilot or the AI packages; and if you leave Copilot unchecked in the list, it is not removed.
- **Renames**: **Remove apps** is now **System apps** and **Turn off services** is now **System services** (card, window, dialog and summary); internal ids do not change. Remove old / modern apps keep their names.
- **A single warning icon on cards**: the ⚠ in the title is no longer repeated at the start of "May cause problems", "Can't be undone" or "Heads up", and it sticks to the last word, so if the title wraps the icon wraps with it instead of sitting alone on another line.
- **Riot Vanguard is removed more thoroughly**: it sets the `vgc` and `vgk` services to Disabled, stops and deletes them checking each step, removes the `vgk` driver from the Windows driver store (`pnputil`), deletes Vanguard's scheduled tasks, service keys, tray startup entry and folders, and the summary says what was removed and what is left. It does not touch the Riot client or the games. It always asks for a restart and says it loudly, in the dialog and in the options' warnings: **restart the PC without fail before reinstalling Vanguard (or opening VALORANT or LoL)**, or errors and install loops can happen.
- **Final summary shows only what was done**: the "What was applied" list shows only the options that changed something (the ones already set or not applicable stay in the log), lists the ones that failed apart, and if nothing changed it says a single line: "Nothing needed changing: everything was already set."
- **What's new on the home screen: the latest version and a link to the rest**: it shows only the latest version, with bold titles and in the app's language. If it is very long (over 2000 characters) it is cut at the last bullet boundary that fits, never in the middle of a bullet or a word, and says "The rest of this version and the full history are on GitHub"; if it fits entirely, it says "Previous versions are on GitHub". There is always a link to the repository's CHANGELOG (the one for your language). It is read from the file already in the folder, so it works without internet.
- **OneDrive is cleaned up even if the program is gone**: before, if `OneDrive.exe` no longer existed (from an old or half-finished run), nothing else was cleaned. Now, if you choose OneDrive in **System apps**, besides uninstalling it, it removes its leftovers: the `Microsoft.OneDriveSync` package, the technical folders `%LOCALAPPDATA%\Microsoft\OneDrive` and `%ProgramData%\Microsoft OneDrive` (only if they hold no shortcuts and are not inside your files folder), OneDrive's scheduled tasks and its Start menu shortcut, and the Explorer pane entry even if it only exists in HKCU. It also detects the `OneDrive.App.exe` of newer versions. In the list it shows as **Leftovers remain** and can be checked to clean them up. **It never touches your files folder**, and if your Desktop, Documents or Pictures are inside OneDrive it neither uninstalls nor cleans anything: the final dialog explains it and how to move them back (right-click the folder > Properties > Location > Restore Default > Move). The log and the summary say what was cleaned and what is left. It does not add the policy that prevents reinstalling it, so as not to block OneDrive if you want to use it later.
- **Turning off the antivirus while Tamper Protection is on**: detection now uses two signals (`Get-MpComputerStatus` and the `TamperProtection` registry value) and, if it cannot tell, it counts as on and asks you to turn it off (it opens Windows Security at the right page) instead of continuing silently. If the antivirus still does not turn off, the summary clearly says it is **STILL ON**, why, and how to turn off Tamper Protection; the counters match the FAIL lines in the log (3 failures are no longer reported as 1) and no restart-before-playing-Valorant notice is shown, nor is Vanguard touched, if the antivirus was not turned off.
- **More legible blue counters**: "N/M off" and "N/M off your PC" now use very light blue text on saturated blue in the dark theme (7:1 contrast) and dark blue text on light blue in the light theme.
- **Moving OneDrive folders no longer mistakes cloud folders for links**: the pre-check treated any folder with the reparse point attribute as a "link", and OneDrive folders with Files On-Demand have it. It now reads the real tag: only junctions and symbolic links block; cloud tags (`0x9000X01A`) are walked as normal folders. Cloud-only files still block (it tells you which and how many, and to use "Always keep on this device"). If source and destination are on the same drive it moves by renaming (a metadata change: nothing is copied or downloaded and no space is needed); on another drive it uses robocopy. The final dialog states the real cause of each block (cloud-only, links, open files, space, long paths).
- **Logs are written as UTF-8 with BOM**: before they were saved as ANSI and a UTF-8 reader failed on accents ("Imágenes"). If an old ANSI log already exists it keeps ANSI so the two are not mixed.
- **OneDrive gives your folders back before uninstalling**: if your Desktop, Documents or Pictures (and Music, Videos or Downloads) are inside OneDrive, choosing OneDrive in **System apps** makes Brío show which folders, from where to where, how many files and GB, and ask for confirmation (**no automatic undo**: Restore does not undo it, and the paths of git repos, projects, shortcuts and game saves change; close editors, terminals, Claude Code, git and games first). If you confirm, it checks everything before moving: nothing cloud-only, free space, long paths, links and open files; if anything fails nothing is moved. It moves with `robocopy /E /MOVE` without `/PURGE` or `/MIR` (it never deletes anything at the destination; if a file with the same name exists, the OneDrive one is kept as "name (desde OneDrive)"), verifies by count and size and only then points the folder to `%USERPROFILE%\...` and restarts Explorer. If something was not moved, that folder stays as it was and OneDrive is not uninstalled; the manual steps remain. It never touches `C:\Users\<user>\OneDrive` or any other files.
- **New option "Scale by resolution"** (Gaming, Mouse section): you pick a base resolution (for example 1920x1080) and, when you use a higher one, Brío raises that monitor's Windows scale (125 %, 150 %...) so icons, text, folders and the cursor look the same size as at the base. It only goes up: it never exceeds the maximum Windows offers for the monitor, never goes below what you had, and with the same or a lower resolution it touches nothing. It waits for the resolution to settle and changes nothing while a game is fullscreen; if it fails, it goes back to the previous scale. Programs that were already open may not resize until you reopen them, and Windows may ask you to sign out (Brío does not sign you out). Restore brings back your scale and cursor.
- **Submenus to choose what to touch**: when you tap Apply, **Clean up startup**, **System apps**, **System services** and **Remove legacy / modern apps** open a list, one after another. Each item has its icon, a clear name, a short description and a tag (**Safe to remove**, **Driver or peripheral: better keep it**, **Protected by Windows**). You confirm and the app carries on with the rest by itself.
- **System apps** adds OneDrive (closes it, runs `OneDriveSetup.exe /uninstall` from System32 and SysWOW64 and removes it from File Explorer and startup), Adobe Express, Quick Assist, Start Experiences, Paint, Sticky Notes, Clock, Camera, Media Player and **protected** apps (Edge, Bing, Get Started), which are removed with the Windows app-retirement method and warn you first because they are not easy to revert.
- **Clean up startup** reads `Run` in HKCU and HKLM, `StartupApproved`, the Startup folders and Store apps, and tags what is safe to remove (OneDrive, Discord, the Defender icon...) and what belongs to drivers or peripherals (Realtek, AMD, Logitech G HUB...).
- **System detection**: Brío knows whether it is a laptop or a desktop, the brand and model of the computer and motherboard, and whether Windows already comes trimmed (Tiny10/Tiny11, AtlasOS, ReviOS, Lite editions). On laptops it does not turn off Wi-Fi, sensors, biometrics, Bluetooth or power saving; on trimmed Windows it does not remove apps again.
- **Complete English texts**: profiles (name, what it does, ideal for, careful, what it does not touch and estimated use), the Competitive and Competitive - Laptop warnings, the add-profiles, delete-parts-of-Windows and local-account prompts and the counters showed in Spanish in English mode. The **Minimum RAM** profile no longer has "(extremo)" in its name. New `tests\Verificar-Textos.ps1` warns if Spanish text is left untranslated.
- **System apps: what is left "pending restart" is no longer a failure**: when removing a protected app (for example Eye control, Parental controls or Exam browser), Windows sometimes marks it as "pending removal" for the system and finishes removing it on restart. Brío now counts it as done, logs it as "completes on restart", the list and the counter show it as removed with the tag "Removed after restart" (it is not offered again) and the final summary says "Restart to finish removing: …". It is a failure only if it was not marked in any way.
- **System apps: list in sections with their total**: Pending, Protected by Windows, Already removed (includes "Removed after restart") and Already gone from your PC. Apps from Brío's list that are no longer installed (LinkedIn, Adobe Express, Microsoft Solitaire, Teams, Spotify, Netflix...) are always shown, in gray with "Already gone from your PC", and **do count** toward N/M. What Windows needs to start up is not shown or offered. What can be removed with care (Print dialog, Contacts, Print queue, Eject external graphics card, Pin to Start, Capture picker, Windows content, Edge developer tools, Xbox game pop-ups) shows among the protected ones.
- **Bigger System apps submenu in columns**: it opens in a window of 80 to 90 % of the work area (it adapts to small screens like 1366x768) with the list in columns that fill from top to bottom, same-size items with text cut with "…" and the full detail in the tooltip, and the buttons always visible at the bottom. System services and Clean up startup stay as they were.
- **System apps: list and counter always match**: the card counter ("N/M gone from your PC", with the note "Includes the ones that were no longer installed") and the submenu list now come from the same source (what is really installed), so it can no longer say "2/2" with 3 apps in the list. Apps Brío already removed also show in the list, in gray, tagged "Already removed" and cannot be checked; if you reinstall one it goes back to pending. **Criterion change:** any app Brío knows about that is no longer on your PC counts as done, whether Brío removed it (even if an old version did not record it), you did, or Windows did, without claiming who removed it; the total is everything Brío knows how to remove.
- **System apps: Windows-protected apps can also be removed**: Edge, Bing, Get Started, Cross-device experience, Widgets, Copilot and other optional ones (Narrator guide, Parental controls, Eye control, Kiosk mode, exam browser) show with a warning icon and the tag "Protected by Windows: not easy to undo"; checking them brings up the 3-button dialog (Cancel / Everything except this / Apply). It is an allow-list: what Windows needs to start up, the Start menu, search, Settings, the account, frameworks and runtimes is never offered or touched, and the script itself also refuses to remove it. Fixed: the script safeguard wrongly blocked Kiosk mode (`LockApp`) and Bing (`Search`); the allow-list now wins and the safeguard only stops critical names that are not in it. If an app is skipped because Windows needs it, the summary says so ("Could not remove (Windows needs it)") instead of counting it as done.
- **Reduce browser bloat**: the "Reduce Edge bloat" and "Reduce Brave bloat" options are now a single one (id `eb`). It detects which browsers are installed (App Paths and install folders) and applies only each one's settings: Edge, Brave or both; if neither is installed, the card says "Not needed". It keeps every setting and the restore of each browser (restore removes both). If you had either old option applied it is recognized as is, since it uses the same policies, and the profiles use the single option.
- **"N/M off" counter** on **System services** (and "N/M removed from startup" on **Clean up startup**): it counts only the services that exist on your Windows and are **disabled** (one on Manual or Active does not count as off, running or not); it refreshes by itself after applying or restoring and is read in the background, so the window never freezes.
- **Turn off services and Extreme services are now ONE option, "System services"**, with a big window in columns: **Safe to turn off** (checked by default), **Extreme** (with a warning, unchecked, each one says what you lose) and **Off** (from each service's real state, so it looks right even if you had applied either of the two old ones). Each service shows its real state (**Active**, **Manual** or **Off**): only a **disabled** one counts as off, and one on Manual or Active is turned off only when you check it. The **Off** ones can be checked to **turn them back on one by one** (they go back to their saved start type, or to the Windows one, and Brío notes it in the log if it had not saved it; before applying it shows a summary of how many are turned on and off) (the "Already off on Manual" section was removed: the previous version counted a Manual and stopped service as off, which was misleading). It adds 13 new services (Offline files, Remote management, AllJoyn router, Diagnostics collector, Scanners and cameras, Shared camera, Folder sharing, Hyper-V and Mixed Reality, among others); nothing already turned off by other options is repeated (telemetry, location, maps, error reporting, printing, Bluetooth, Xbox, search). **Restore** puts each service back to the start type it had before being turned off (saved in `ProgramData\Brio`) and still re-enables the biometrics that earlier versions turned off. **Windows Hello and the PIN are out of the list** (Biometric, Passport, keys, Credential Manager, Bluetooth and Web Account Manager are not offered here). Services that touch smart cards and security keys, the Windows Hello face camera or Phone Link show as Extreme with a red tag and, if you check them, a 3-button dialog explains what stops working and how to undo it. The card counter is off / all the services the list offers on your PC, counting only the disabled ones (for example "29/37 off"); it turns green ("Already applied") when all the Safe ones are disabled. **Criterion change:** before, a Manual and stopped service counted as off, now it does not. If an earlier version of Brío left biometrics (Windows Hello fingerprint or face) disabled, the window warns you and **Restore** puts it back to Manual. The **Minimal RAM** profile applies the Safe ones and the Extreme ones that do not touch signing in; the other profiles apply only the Safe ones. No service in the list affects Snipping Tool (Win+Shift+S).
- **3-button dialogs** (Cancel / Everything except this / Apply) on the Xbox, Game Pass and Minecraft warning, the no-way-back warning and the protected apps warning: **Cancel** (or Esc) applies nothing and goes back to the screen, **Everything except this** applies everything else and unchecks only those settings, **Apply** applies them with the rest. With a one-click profile, Cancel stops the whole profile and leaves the screen with nothing checked.
- **Connected devices warning**: before applying, Brío reads what you have plugged in (USB and PCIe audio interfaces, ASIO drivers, MIDI, Bluetooth, printers, joysticks, biometrics, cameras and scanners, card readers) and, if something you selected may cause problems with it, shows "Detected: <name>" with the 3-button dialog. It covers Priority for games, System timer, processor idle states, PCIe and USB power saving, Bluetooth, printing, sensors and biometrics, smart cards and Delete unused drivers. If nothing is detected, no dialog is shown; the Priority for games, Timer, System services and Delete drivers cards add a "May cause problems" line.
- **Gamer zone, Keyboard**: **Unstick keyboard** (a background program releases Alt, Ctrl, Shift and Windows if they stay pressed for 30 seconds with no input, and keeps the **Ctrl + Alt + K** shortcut always on) and **Focus mode** (ignores the Windows key while a game is in full screen; **Ctrl + Alt + F** blocks it always and goes back to automatic). Both start when you sign in, reset from the app and drop their keyboard hook when turned off. Focus mode warns that some anti-cheats distrust programs that watch the keyboard.
- **Gamer zone, Mouse: Fixed pointer speed** (new, not in any profile): a background program (`BrioPuntero`, same mechanism as BrioTeclado and BrioFoco: logon task, updates itself and is removed by Restore) changes the Windows pointer speed when you change resolution, without signing out. You pick a base speed from 1 to 20 (10 = the Windows one) for the primary monitor's native resolution (the largest one it offers, saved in `ProgramData\Brio`) and, at a lower resolution, the speed is adjusted to the nearest step of the Windows table (for example, 2560 to 1920 with base 10 gives 8, and to 1280 gives 6). It turns off acceleration (the compensation assumes a linear curve) and saves your previous speed and acceleration to give them back on Restore. Games with direct input (raw input) are not touched. **It conflicts with Competitive mouse**: checking one with the other, Brío asks which to keep. The calculation has a self-test in `tests\Verificar-Opciones.ps1`.
- **Optimizations for windowed games**: the description adds a tip for the black screen when pressing Alt+Tab from a fullscreen game (try borderless windowed mode).
- **Tools**: **Scan and repair Windows** (DISM + SFC, with your permission), and **Local account without Microsoft** (creates a local administrator with no password or email; it is locked if you are already on a local account and warns about files, saves and BitLocker first).
- **Update to Windows 11 26H2** no longer opens a black window: from Windows 10 (any version) or an old Windows 11 it uses the official ISO, and from 24H2/25H2 Windows Update. First it checks and fixes what blocks the update (damaged Windows, Windows Update off or paused, options that block it, low space, pending restart).
- **Favorites with ⭐**: Nitro Mode (aka QuickCPU), System timer (aka TimerResolution), Turn off the antivirus, Disable memory integrity and Disable VBS.
- Gaming helper programs (BrioAfinidad, BrioRAM, BrioTimer) left by an old version **update themselves** when the app opens.
- The final summary after applying is more complete: how many settings, what was applied, space freed (from 1 MB; before, only from 50 MB), apps removed, what no longer starts with Windows and the chosen DNS.
- **Collapsible categories** in Debloat and Gamer zone: tap a category title (or use Tab and Space/Enter) to fold or unfold it. Each title has an arrow, says how many options it has and, in light blue, how many you ticked (visible even when folded: folding only hides, what is ticked is still applied). The app remembers what you left folded (app_config.txt, key `plegadas`; if it is missing or a name no longer exists, everything starts unfolded). The search bar unfolds the categories with results while you search and, when you clear it, they go back to how you left them. Not added to Clean cache and Tools: they have few options, and in Clean cache folding could hide something ticked that deletes files (Downloads, app leftovers).
- **Order by impact**: inside each page, what gives the most real performance goes on top and the marginal stuff at the bottom. Criteria (no percentages, it depends on each PC): 1) what changes FPS, stutter or frametime in Gamer zone, and what frees RAM, CPU and disk all the time in Debloat; 2) latency and responsiveness (timer, network, mouse, DNS); 3) comfort, interface and privacy (grey titles). At the same level, the safe stuff first and then what carries risk; what cannot be undone always goes last. The list is written and commented in Brio.ps1 (`$OrdenSec` for categories and `$OrdenOpc` for options). The order in which things are applied did not change.
  - Gamer zone: Graphics, Game Mode and Game Bar, CPU and priority, Processor, Power plan, RAM cleanup, Security (most performance); then Timer, Power and network, Mouse, DNS; at the end Keyboard, Sound, Search/storage/Explorer and Extra settings. "Prefer IPv4" moved to Power and network.
  - Debloat: the giant "System and privacy" category was split into Background apps and processes, Visual effects and smoothness, Updates and Store, Services and features almost nobody uses, Apps, browsers and AI, Privacy and telemetry and Interface and comfort. Order: background, effects, storage and memory, updates, services, security, apps/browsers/AI, privacy, interface, restore points and removing parts of Windows.
- **Split options**: those that did several things in one checkbox are now separate options, each with its own explanation, status reading, Apply and Restore. The original id stayed for the main part. If you already had the big option applied, each new part reads its own status and shows as applied.
  - Data tracking and collection -> activity history, location, Wi-Fi Sense, cloud settings sync, typing learning, cloud speech, automatic map downloads and online DRM (with HomeGroup, which no longer exists).
  - Ads, suggestions and Bing -> ads and suggestions / Bing and web search in Start.
  - Windows sounds -> sounds / startup sound. Visual effects -> effects / transparency. Widgets -> Widgets / Task View button.
  - Printing, local network and Remote Desktop -> printing / network discovery and casting / Remote Desktop.
  - Connected devices and clipboard -> shared experiences / clipboard history. Fast shutdown and startup -> fast shutdown / startup programs wait.
  - Legacy features -> Remote Assistance / AutoPlay / error reporting. Program telemetry -> Office / NVIDIA / PowerShell 7.
  - Edge and Brave bloat -> Edge / Brave. AI features -> Windows AI / Notepad and Paint / Copilot in Word and Excel.
  - Gamer zone: hardware GPU and windowed games -> hardware-accelerated GPU / windowed game optimizations (Windows 11 only). Extensions and hidden files -> extensions / hidden files. USB, PCIe and disk power saving -> USB / PCI Express / disks.
  - Not split (and why): lists that are one thing (junk apps, old components, telemetry tasks, hosts servers), the competitive mouse (speed and trail stay at the Windows value both when applying and restoring), Windows telemetry (lowering the service and leaving the level to receive new versions go together), each game's fullscreen and DPI (same registry value) and "Services and features almost nobody uses" (its Windows features cannot be read quickly without DISM).
- Profiles (Safe, Optimized, Competitive, Light RAM, Minimum RAM, laptop and Full) include the new parts of each option they already had: they apply exactly the same as before. The parts keep the original option's warnings (so "Tick only safe ones" does not tick anything new), the restart request (except windowed games, which take effect when you reopen the game) and the Windows version requirements.
- **Count bubble in each section** of the left menu, same as the one in Recommended configs (same style, in the corner). It counts by itself from what the app loaded: Profiles = profiles; Debloat and Gamer zone = options you can use on your PC (greyed-out ones for your Windows version, Windows 10/11 ones on Windows 7 and 8, and ones not needed for your hardware are not counted; it is recalculated after reading Windows and with "Re-read settings"); Clean cache = options to tick; Tools = tools; Recommended apps = apps. Home has none.
- `tests\Verificar-Opciones.ps1`: automatic check that fails if there are repeated ids, if a translation, a status check or the place in the impact order is missing, or if a split option is not in the profiles that had the original.

### Changes
- **Shared camera (cam)**: on recent Windows 11 each camera has its own "Allow multiple apps to use camera at the same time" switch and Brio cannot change it by itself. The option now turns on Windows' general mode and opens the Cameras page in Settings so you turn it on by hand (before, it said it turned it on and on some PCs nothing happened). The texts explain it.
- **Warning for dual-CCD Ryzen X3D** (7900X3D, 7950X3D, 9900X3D, 9950X3D) on **High performance plan**, **Nitro mode** and **Always-awake cores**: the AMD driver needs the Balanced plan to park the non-V-Cache CCD, so leave them unchecked. It is only a warning, they are not skipped.
- **Profiles also offer to move your OneDrive folders**: if the profile removes OneDrive (and you did not choose to keep it) and your Desktop, Documents or Pictures are inside OneDrive, the usual dialog appears before uninstalling it. If you do not confirm, OneDrive is not uninstalled.
- **OneDrive cleans more leftovers when uninstalled**: besides `%LOCALAPPDATA%\Microsoft\OneDrive` and `%ProgramData%\Microsoft OneDrive`, it now also deletes `%LOCALAPPDATA%\OneDrive`, `%APPDATA%\Microsoft\OneDrive` and `C:\OneDriveTemp` (if they exist and are not shortcuts), and closes OneDrive if it was still running. The `%USERPROFILE%\OneDrive` folder is only deleted if it is completely empty; if it holds anything it is left alone.
- The tests (`tests\`) are no longer uploaded to the repository: they stay only in your local copy.
- **One-click profiles**: "Apply profile" applies directly, without clash prompts or lists. If the profile needs missing drivers it **is not applied** until you install them (the button takes you to Tools). Performance profiles also remove OneDrive and the Defender icon from startup.
- **Clashes**: a single prompt with the current option against the new one to choose which stays; it no longer repeats when applying (it looked like a loop). If you fully turn off Windows Update, Xbox or the Microsoft Store, their child options are greyed out.
- Short, clear names (Clean up startup, Remove apps, Turn off services...), an emoji on each category and double dividers at the start and end of each one.
- The changelog and loading texts show up in your language.
- **Measure FPS before and after** was removed. BIOS settings are still in Tools.
- Options that can **block updating to 26H2** are flagged (compatibility inventory, diagnostic tasks, telemetry in hosts, Windows Update off or paused).
- Xuca OPtimizer was renamed **Brío** (repo github.com/011Xuca/brio).
- Own color: sky blue (#60A5FA in dark, #1D4ED8 in light) in buttons, borders, selection and the icon (border and drawing). The app background becomes the icon's dark grey.
- App data (preferences, reading logs, Gaming helper programs and their tasks) moves to ProgramData\Brio. The first time it opens they move on their own, losing nothing, and the helper programs that were running are turned on again.
- Recommended apps: the PC monitor card is now **Pulso** (github.com/011Xuca/pulso).
- If you had Xuca OPtimizer, it updates itself to Brío from the update prompt: it downloads the new app and the desktop shortcut is renamed Brío.

### Fixed
- **Windows "not activated" or "not genuine" on a local account**: "Turn off Store installs" turned off LicenseManager, which activation uses. It is no longer turned off, no option can turn off `sppsvc`, `ClipSVC`, `LicenseManager`, `wlidsvc` or `KeyIso` or the license tasks, the hosts file never blocks activation servers, and if any was left off by an old version it is fixed automatically.
- **Snipping Tool and Win+Shift+S stopped working** without warning: "Turn off per-user services" turned off the clipboard (`cbdhsvc`). It no longer touches it and turns it back on if it was off.
- **Turning off Windows Update completely did not last**: the Windows Update Medic and the Orchestrator tasks turned it back on, and on Windows 11 `UsoSvc` could not be changed. Now they are turned off too, as SYSTEM when needed.
- The 3 errors of "Delete accessibility and speech" (`raiz de registro desconocida: HKCU:`): the registry accepts both ways of writing the path.
- The pause to turn off **Tamper Protection** before turning off Defender checks that it is really off and waits for you to confirm.
- "Reduce telemetry" no longer turns off the compatibility appraiser (without it Windows Update does not offer 26H2).
- The final Debloat summary now also counts PowerShell errors (PS-ERROR) and pending items, not only FALLO. Before, it said "all good" even when options failed.
- When it finishes it shows "All went well" or the list of what failed or is pending.
- Fixed "Item not found" when removing or reading Windows components (old apps, languages, accessibility): it is now noted as a warning and continues.
- Fixed pnputil and dism not being recognized on PCs with System32 outside the PATH (unused drivers, component cleanup).
- Updater: if a file could not be replaced (open in another program or the antivirus), the app was left half new and half old. Now it saves a copy of each file before overwriting it and, if something fails, puts everything back as it was.
- Updater: if a file is locked for a moment (for example, the antivirus scanning it) it retries, and if another window of the app has it (another open copy or a tool in its console) it closes it by itself before replacing it. Then, as always, it closes and opens the new version.
- Updater: read-only files no longer make the update fail.
- Updater: the app kept its icon locked while open and the update could not replace it. Now it reads it into memory.
- Restoring the antivirus now also removes Edge's SmartScreen policies (before, Edge stayed without SmartScreen and said "managed by your organization").
- Updater: on Wi-Fi with a login page (hotel, cafe) a false "new version" no longer appears.
- Updater: if the network hangs while looking for new versions, the app opens anyway after 8 seconds.
- If you tap "No" on the Windows permission prompt, the app closes without showing an error.
- Windows tools (sc, reg, powercfg, icacls, DISM...) are found even if the PC lacks System32 in the PATH.
